## 📝 Descripción del Proyecto

**Bubble Tea Fuxion** es una aplicación web promocional e interactiva diseñada para una marca de bebidas y postres. Cuenta con un diseño moderno, responsivo y dinámico que incluye un módulo de **ruleta de premios gamificada**, permitiendo a los clientes girar y ganar descuentos o productos en tiempo real para mejorar la conversión y experiencia de usuario.

---

## ⚙️ Características Principales

- 🧋 **Landing Page Comercial:** Presentación de la marca, catálogo visual de sabores y llamados a la acción (CTA) orientados a pedidos.
- 🎡 **Ruleta Gamificada:** Animación interactiva en Canvas / CSS Keyframes alimentada con lógica en JavaScript para la asignación de premios aleatorios.
- 📱 **Diseño 100% Responsivo:** Adaptación fluida para smartphones, tablets y pantallas de escritorio.
- ⚡ **Despliegue Continuo:** Publicado mediante GitHub Pages para acceso directo desde cualquier navegador.
